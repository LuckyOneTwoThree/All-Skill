# Stage-P: Prototype Output (Prototype Mode Only)

Executed only when `mode=prototype`. After project-init completion, outputs visual direction and constraint review results without generating page code.

```
Action: Prototype Output
Trigger Condition: mode=prototype
Input:
  visual_direction: output/ui-project-init/project-init.json -> visual_direction
  tokens: output/ui-project-init/project-init.json -> tokens
  component_library: output/ui-project-init/project-init.json -> component_library
  constraint_review: output/ui-frontend/constraint-review/constraint_review.json (optional)
  design_explorations: output/ui-frontend/design-exploration/design_explorations.json (optional)
Process:
  1. Summarize visual direction, design tokens, and component library selection from project-init output
  2. If constraint review results exist, include in prototype report
  3. If design exploration results exist, include in prototype report
  4. Generate prototype report (including visual direction summary, key page layout sketch descriptions, component selection summary)
  5. Do not generate page code, do not invoke ext Skill, do not generate design_brief
Output:
  output/ui-frontend/prototype/prototype-report.md -- Prototype report
  output/ui-project-init/ -- Design system output (already generated by stage-1)
Validation: prototype-report.md generated + visual_direction 10-dimension definition complete
Mode: AI
```

**Prototype Mode Trade-offs**:
- [OK] Gain: Rapid validation of design direction, low-cost multi-scheme comparison, interaction logic alignment
- [X] Forgo: Page code, ext enhancement, quality audit, API integration, production readiness

**Prototype Mode Output**:
- Prototype report (markdown): Visual direction summary + Key page layout descriptions + Component selection summary
- Design system output (project-init.json): Visual direction + Design tokens + Component library
- No page code, no design_brief, no quality_debt

**Connection with Full Mode**:
- After prototype completion, user confirms visual direction and component selection
- When switching to full mode, execution starts from stage-2 (skip stage-1, reuse existing project-init output)
- Must preserve project_dir during project information collection to ensure full mode can locate existing output
